# Scope and causal attribution

Only this new isolated package and its new test file are changed. The previous
ReferenceEngine, EffectEngine, native projection, Core effect tail, reports,
production Core, body, catalog, sampler, binder and frozen components retain their
bytes. RealEffectCore explicitly inherits the existing TEST_ONLY lifecycle.
Production A selection and existing databases are never used.

The only new formation input is owned request/receipt incidence. RealEncoder
retains native execution records separately from synthetic typed receipts.
RealEffectEngine inserts exact receiver→observed-operand incidence during the
ordinary integration hook, before calling the unchanged parent formation rules.
The parent forms value transitions, compositions and EffectRoutes; the parent
ordinary read constructs effects and operations before normal comparison. The
parent tail dispatches them. There is no new consumer, selector or action mapper.

Required-parameter names in the real receipt identify the corresponding declared
protocol slots, not preferred behaviors. Arguments must also have exact typed
evidence in the renewed frame; the adapter never synthesizes a sensor operand
from a command. This establishes recorded co-incidence, not action→world causality.

Native JSON Schema `required` has set semantics. The carrier sorts that array for
the existing exact declaration validator, preserves its original wire form in
`nativeDeclarationWireSource` (external audit, ignored by FrameEncoder), and leaves
every code, property, domain, numeric channel and observed object intact. Duplicate
required names reject. No capability or actual input is dropped to meet capacity.

The single bootstrap entry is external and explicitly labeled. It is reserved
persistently before the call and has no retry. Tick/advance never call it. No
future action is copied from it; future action content, if any, must be supplied
by the unchanged ordinary occurrence mechanism. The fixed bootstrap need not
produce a successful training transition. Failure is evidence, not permission to
change the action or manufacture inputs.

Offline tests use a distinct OFFLINE_RECEIPT_ADAPTER_TEST source. The real runner
uses MinecraftBridge, an independently named body, no reconnect, and a fresh
database. Recording and schema decoding are external mechanics. Bootstrap code
and value are external initial conditions. Any later route, endpoint propagation
and parameter candidate are attributed only to the documented candidate law and
its actual input supports, never autonomous goal or action-selection authorship.
