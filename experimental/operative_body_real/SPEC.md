# Real native receipt carrier — preregistered before execution

This is interface wiring for the existing occurrence-effects experiment, not a
new formation law. Previous files and evidence remain unchanged. Fresh isolated
database, individual and body username; no imported state or synthetic training.

One external bootstrap is fixed before connection: native catalog version 2,
code 16, parameters {"slot": 0}. This is an experimenter-supplied initial condition,
not autonomous action selection. Unavailable or incompatible declaration stops
the run without changing the operation or retrying. The full native catalog and
all raw observation channels remain intact. No input filtering or cap increase.

The actual Core action identity, native request and matching successful receipt
are associated with the already committed before frame and the next fresh frame.
Receipt parameter fields identify declared slots mechanically. Only a parameter
also present as an exact typed value/reference in that fresh observation is an
admissible operand. Missing incidence rejects without fabrication or fallback.
The receiver binding is recorded during ordinary integration, with the original
receipt, request, frame identities and integration/experience support. The
unchanged EffectEngine forms and later activates EffectRoutes. An old action is
never copied as a future expression.

The bootstrap is at most one call. Subsequently only the unchanged ordinary
effect mechanism dispatches. No retries, further demonstrations, forced input
changes, sampler, binder, selector or historical queries. Retain at most eight
fresh observations, with a 30-second observation window after body startup.
Stop on transport, admission or capacity rejection and preserve the evidence.
The resource envelope and 64 Unit/content limit are unchanged.

Checks: matching receipt admission; missing/currently unobserved operand rejection;
synthetic premise rejection; same-Core action/interval ownership; ordinary formation
and later activation; receipt/renewed input feedback; ambiguity and no retry remain
covered by the unchanged occurrence-effects tests. Offline receipt-shaped tests
are explicitly mock evidence. Real PASS needs an internally generated operation,
matching real receipt, renewed real input integrated by the same continuous A,
and further recursion. Bootstrap-only is PARTIAL, never real loop PASS. No action
means NOT_READY. Transport before eligible observation is NOT_TESTABLE. Capacity
rejection is RESOURCE_LIMIT, with the last committed evidence preserved.

No claim of autonomous purpose, autonomous tool selection, general causal law,
formal/mainline adoption, arbitrary real-scene capacity or Perfect Recursion proof.
