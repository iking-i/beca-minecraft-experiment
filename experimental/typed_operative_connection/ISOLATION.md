editing those packages. It adds a separately versioned TEST_ONLY graph/lifetime
binding in authoritative Current State. ConnectionEngine inherits the native
input admission and actual FormalL0 operative transition. The only production

## Three distinct structures

1. `operative_test_only.edges`: relation-reference -> relation-reference;
   the previous candidate formation and traversal remain in use.
2. `native_body_operands_test_only.incidence`: first-observed pattern Unit ->
   all declared/observed typed Units; externally supplied representation.
3. `typed_connection_test_only.edges`: specific Unit -> specific Unit,
   DirectedConnection with canonical content identity. Initial S0 and formed S1
   use exactly the same schema and the same ordinary constructor interpretation.

No incidence or relation edge is renamed as the third structure. New S1 edges
come from actual ChangeSet same-channel before/after facts, after ordinary
experience insertion/integration. The inherited hook only runs when a new
ordinary temporal relation is inserted; this finite scope is not a general
all-experiences formation claim. Connections formed there cannot affect that
round's already completed read; they first become operands in a later advance.

The external law gives the before/after orientation and canonical typed encoding;
it does not select numeric literals, ports, slots or channels. All fully observed
numeric changed facts are processed. Shared identities deduplicate identical
connections and retain the forming channel facts as audit support. No Cartesian
product across channels or values is generated. A numeric predecessor/successor
without a previously admitted exact typed endpoint is rejected, not replaced.
Appeared/disappeared/unobserved values with an absent endpoint create no edge;
carrier/namespace gaps never enter ordinary experience integration.

relation cap; content and Units retain the original shared unit cap. Whole
non-fitting transitions reject before commit. Canonical transitions cannot erase
committed typed connections. No pruning, ranking, cap changes or default values.

The decisive scope is synthetic scalar **ObservedValue -> ObservedValue**
transition connections. Ports/slots/domains/references are identical available
native materials, not the formed connection endpoints in the S1 witness. This
proves no slot/value binding, native-port commitment, complete expression,
action/parameter authorship, adoption, body execution, autonomous goal, world
causal law, behavioral closure, L1 or universal recursive mechanism.

The structural observation values are sensor supplied; A is not claimed to
create those values. The new directed relation is integrated from their actual
experienced difference. Both mechanism and synthetic experimental history are
externally supplied; no universal/theory claim follows.
